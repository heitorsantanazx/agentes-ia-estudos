# Estudos de Agentes de IA

## Objetivo

Resolvi documentar os meus estudos sobre agentes de IA através deste repositório, onde eu usei como modelo o gemini 2.5 flash, visto que tem relação com a minha particição no programa GEAR, na qual foi uma trilha que foi oferecido aos participantes do **Hackthon da App Bit** pela **Wongola**.


# Aprendizado

* Aprendi boas práticas sobre como mexer com agentes de IA
* Entendi como funciona o processo de criação de um agente
* Observei na prática como funciona os quatros parâmetros principais de um agente
* Conceitos de "adk web", "adk run" e "adk api_server"
* Percebi o quão importante é você detalhar as instruções para os agentes e também colocar limites
* Uso da biblioteca Pydantic para validação e modelagem de dados em Python
* Ferramenta integrada x Ferramenta personalizada
    * Ferramentas integradas possuem uma baixa complexidade de uso e sua configuração é relacionada com o ato de importar e usar
    * Ferramentas personalizadas por sua vez possuem uma complexidade média, a parte de configuração se trata de escrever implementação da função e são ideias para casos específicos como visto no "geography_assistant"

# Observação

* É importante lembrar que ao usar o método de embasamento da Pesquisa Google (visto no research assistant), é necessário exibir sugestões de pesquisa (renderedContent) na interface do usuário do seu aplicativo. Isso é obrigatório de acordo com a política de uso da Pesquisa Google.
